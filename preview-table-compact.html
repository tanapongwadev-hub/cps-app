สรุปการเปลี่ยนแปลง (Compact & Dense)

  • ไม่มี background/box รอบ cell — ใช้ padding + spacing ล้วน ๆ ให้ cell ดูเป็นส่วนหนึ่งของ table
  • Thumbnail 40×40px (จาก 56) + rounded-4px (จาก rounded-md) — เล็กกะทัดรัด ไม่เด่นเกินไป
  • Active dot ที่มุมล่างขวา (จากมุมบนขวา) — เป็น visual hint เบา ๆ ไม่บังรูป
  • 2-line content:
    • Line 1: code · unit · name — inline 1 แถว ใช้ dot separator
    • Line 2: รุ่น: X · จัดส่ง: Y — inline label:value ไม่มี chip
  • Code เป็น text ล้วน (mono, primary color) — ไม่มี gradient/background — เบาที่สุด
  • Meta เป็น text 11px ไม่ใช่ uppercase label — ใช้ : แทน dt/dd เพื่อความกระชับ
  • Row height เล็กลง (py-2 จาก py-3) — เห็น row มากขึ้น 30% ใน viewport เดียว
  • Cell padding uniform ทุก column ใช้ py-2 — ไม่มี cell เด่น/เตี้ย
